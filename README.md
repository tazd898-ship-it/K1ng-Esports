# K1ng Esports

Official K1ng Esports website.

## Pages
- Home
- Team
- About Us
- Live Status
- Announcements

## Publish the site
A GitHub Actions Pages workflow is included at `.github/workflows/pages.yml`.

If GitHub Pages has not started automatically, open **Settings → Pages** in this repository and set **Source** to **GitHub Actions**. The next push to `main` will deploy the site.

## Customisation
Replace the placeholder roster names, match information and social links with official K1ng details before publishing them publicly.
